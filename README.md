# ☕ Desenvolvimento de Sistemas I - Gabriel Camara

Repositório para as aulas de **Desenvolvimento de Sistemas** com o professor **Davi Vilar**. Este repositório contém os projetos e exercícios realizados durante o curso.

## 📝 Metodologia

As aulas foram divididas em:
- **Listas de exercícios:** resolvemos problemas práticos em Java, aplicando os conceitos teóricos vistos em aula.
- **Desenvolvimento incremental:** começamos com fundamentos, como manipulação de variáveis e controle de fluxo, e avançamos para tópicos mais complexos.
- **Pequenos projetos:** criação de **frames e interfaces** utilizando bibliotecas de Java como **Swing**, focando em interatividade e boas práticas de organização.
